## 0. 结论先说

1. **§6.3 的 4 类不够用。** 4 类（失业、医疗自付、生活成本、权益回撤）只够撑起"冲击型事件"，撑不起卡片前提里那句"第 3 月失业、第 8 月开销偏高"之外的任何真实感。实际需要 **10 个门类、54 条候选参数**（§1、§2，计数见附录 C）。
2. **54 条候选参数里，43 条是公开口径（其中第三方/智库 8 条、背景 1 条，`label` 必须写机构）、7 条只能当压力假设、2 条制度口径（走 `USER` 或规则开关）、1 条派生示例、1 条仅作叙事参考不计入**（明细见附录 C）。三类必须分开标记，否则 `basis` 只有两个值会逼着人把推导值伪装成"公开统计"（§4）。
3. **同类项目分三派，我们只借两派：** 借"历史回放"的纪律（cFIREsim / FIRECalc：用真实历史序列，不预测）与"结果分档"的做法（ProjectionLab：分档口径自己定）；不借"成功率百分比"的叫法（与我们"在 N 条里有多少条"的口径冲突，§3）。
4. **两个 schema 缺口**（建议在 P0 契约冻结时一起定）：
   - `basis` 需要第三个值 `DERIVED`，或给 `Param` 加 `derivation: { formula: string; inputs: string[] }`；
   - 参数包需要"事实层 / 假设层"两层：同一份快照里既有"统计公报说 5.2%"，也有"我们假定失业后先等 6 个月"，两者不能放在同一个数组里不加区分。
5. **P1.5 估时从 1d 调到 1.5–2d**：门类翻倍、每个门类要"命中即引用 / 未命中即回落"两条路径、外加引用逐字校验的测试。

## 2. 已核实的真实数据

> 每条给：取值 → 出处 → 逐字引用。表中 `建议 basis` 列用简写，正式枚举如下：`PUBLIC` = `PUBLIC_STATISTIC`（可写"公开统计"）；`DERIVED` = 由公开数据算得（必须有公式）；`ASSUME` = `PRESS_HYPOTHESIS`（只能写"我们假定"）。实现与快照一律用正式枚举，不用简写。
>
> 括号里的 `（第三方）/（智库）/（背景）` 对应 `sourceQuality`：`OFFICIAL`（政府统计与法律原文）/ `THIRD_PARTY`（行业协会、保险公司数据）/ `THINK_TANK`（研究机构估算）。只有 `OFFICIAL` 可以说"国家统计局数据"。

### 2.8 H 失业保障（制度层）

已在 2.1 给过期限表。补两条口径：

- 失业保险金**标准**由省级政府定，不得低于城市低保（社保法第四十七条），所以全国没有单一数值——**不要写"每月 X 元"的全国参数**，要用"当地低保/最低工资的一个比例"标成 `USER` 或按城市档 `ASSUME`。
- 领取期间医保由失业保险基金缴（第四十八条）。这个细节会显著影响"失业后医疗支出"那条线的真实度，建议在世界线里做成开关。

## 3. 同类项目：三派做法与可借/不借

| 项目 | 形态 | 数据从哪来 | 借什么 | 不借什么 |
| --- | --- | --- | --- | --- |
| [cFIREsim](https://github.com/jcoliz/cFIREsim-open)（开源，JS） | 退休组合"能不能撑住"回放 | 真实历史年度收益 + 通胀序列，滚动窗口 | **用历史窗口而不是概率**；失败年数直接数出来 | "成功率 95%" 这类百分比措辞 |
| FIRECalc | 同派：网页版历史回放 | 同上 | 同上；结果多以分位呈现 | 同上 |
| [ProjectionLab](https://projectionlab.com/monte-carlo) | 商业，蒙特卡洛 | 自定义分布 + 历史回测 | "Backtest your plans against real historical data"；"Define outcome categories as you see fit"（分档口径自己定） | "chance of success" 这种成功概率话术 |
| [Owl / owlplanner](https://pypi.org/project/owlplanner/) | 开源，情景规划 | 用户假设 + 情景 | "场景即输入"的建模方式 | 复杂税制（国内不适用） |
| Portfolio Visualizer | 组合蒙特卡洛 | 历史收益分布 | 多策略同种子对比的呈现 | 把参数当成"市场预测" |
| [人生重开模拟器](https://github.com/VickScarlet/remake)（开源） | 事件牌推进 | 事件权重 + 属性资格 | 事件库结构（v2 已经用了） | "权重即概率"的暗示 |
| 国内基金/组合回测类工具（雪球组合、韭圈儿等；未逐项核实功能细节） | 历史净值回测 | 真实净值序列 | **最大回撤 / 最长回撤期**作为市场冲击参数 | 用回测收益当未来预期 |

三条直接可用的结论：

1. **"回放历史"比"生成随机数"更好解释。** 我们的 D 门类给的是"历史上跌过 72%、跌了 386 天"，不是"我们假设年化 8%"。这正好落在 PRD 的"不预测"边界内。
2. **分档要单一口径，但档位名可以让用户认领。** ProjectionLab 让用户自定义"什么叫成功"；我们不让用户改 `bandOf`，但可以在第 3 屏写"我们把'不够用'定义为低于 3 个月必需支出"——口径透明，不许用户自定义，否则跨卡片不可比（§3.5 的教训）。
3. **这类工具通常只给"分布 + 成败"，不负责"挑一条讲给人听"。** 这是我们可以做差异化的地方：③ 统计选候选 + ④ agent 挑一条写说服点，规格 §5 的分工是对的。

## 4. 数据 → 参数：三档映射

| 档 | 定义 | 例子 | 页面/agent 措辞 | 进快照 |
| --- | --- | --- | --- | --- |
| `PUBLIC_STATISTIC` | 逐字引用命中，数字与取值一致 | 5.2% 失业率；27.5% 个人卫生支出 | "公开统计：…（出处）" | 是 |
| `DERIVED` | 由公开数据按固定公式算得，公式与输入都记录 | `人均自付医疗支出 = 25007.5 亿 ÷ 14.05 亿人`；`月中断概率 = 1 − (1 − 年概率)^(1/12)`；`回撤档位 = 历史五轮分位` | "由公开数据推得（公式）" | 是，但必须带 `derivation` |
| `PRESS_HYPOTHESIS` | 无公开支撑，团队设定，冻结版本 | 失业后 3/6 个月恢复、开销 +5% 档、`medicalCost` 三档 | "我们假定……" | 是，标 `BUILTIN` |

**为什么必须加 `DERIVED`**：`jobLoss` 的月概率、`marketDropRate` 的档位、`floorMinor` 的 3 个月，全是推导值。只有两个 basis 时，实现者只有两个选择——把推导值说成"统计"（违规）或说成"假设"（低估了它的可信度）。加第三档最省事。

**建议的 `Param` 增补**（P0 契约冻结时定）：

```ts
export type Basis = 'PUBLIC_STATISTIC' | 'DERIVED' | 'PRESS_HYPOTHESIS';

export type Param = {
  key: string;
  value: number;
  unit: 'RATIO' | 'CNY_MINOR' | 'MONTHS' | 'DIMENSIONLESS';
  source: ParamSource;              // BUILTIN / SNAPSHOT / USER（没有 WEB，运行时零网络）
  basis: Basis;
  sourceQuality?: 'OFFICIAL' | 'THIRD_PARTY' | 'THINK_TANK';  // PUBLIC_STATISTIC 必填
  label: string;                    // 人话，页面与 agent 直接引用
  derivation?: { formula: string; inputs: string[] };  // 仅 DERIVED
};
```

`sourceQuality` 是这一轮补的第三个字段：**"公开统计"不等于"官方统计"**。43 条公开口径里有 8 条来自第三方或智库（精算协会 2 条、育娲 5 条、房地产投资背景 1 条），只有 `OFFICIAL` 才允许说"国家统计局数据"，`THINK_TANK` 必须说"某智库估算"。没有这个字段，实现者只能二选一：要么把智库数据包装成官方，要么把可引用的研究降级成假设——两种都错。

对应的小改动：§6.5 的 prompt 规则从两档变三档（`PUBLIC_STATISTIC` 才可写"现实中是……"；`DERIVED` 写"由公开数据推得"；`PRESS_HYPOTHESIS` 写"我们假定"）；§10.1 第 9 条测试相应加一条"`DERIVED` 必须带 `derivation`，且 `inputs` 都能在参数包里找到"。

- 原文与转载：统计公报原文在 stats.gov.cn、卫健公报原文在 nhc.gov.cn；本次为取到完整正文，用了官方全文转载（理论中国网转《人民日报》、健康报解读稿）。快照里 `url` 应优先记官方页，转载页作为 `fallbackUrl` 一并保存，且两处 `quote` 必须一致——否则 `DEGRADED`。
- 未采用：付费数据库（Wind/中经网）、需登录的统计年鉴、JS 渲染的图表（国家数据 easyquery）。
- 未逐字核对：cFIREsim 的功能描述（仓库首页只确认了"开源、JS 重写"），Owl 的具体算法。两处只作产品形态参考，不进参数包。
- 数据时效：统计公报均为年度初步核算数，2026 年年报发布后应整体替换并升 `paramsVersion`（`params.v1` → `params.v2`），旧版保留以复现旧报告。
